# chrun_analysis

1.Project Overview

This project analyzes customer churn patterns using Machine Learning techniques.  
The main objective is to identify customers who are likely to leave the company and understand the factors affecting customer retention.

The project includes:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Machine Learning Models
- Customer Segmentation
- Churn Prediction
- Business Recommendations

2.Dataset

Dataset used:
IBM Telco Customer Churn Dataset

Download from Kaggle:
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

3.Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

4.Machine Learning Algorithms Used

. Logistic Regression
. Random Forest Classifier
. KMeans Clustering
